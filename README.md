# PokeNext Launcher

Downloads of the PokeNext Launcher for Windows. It installs and updates the PokeNext modpack, Java and Fabric,
then joins play.pokenext.org.

Get the installer from [Releases](https://github.com/Justchicoo/PokeNext-Launcher/releases/latest) or from
[pokenext.org](https://pokenext.org).

- Sign in with your Microsoft account on Microsoft's own login page; you need Minecraft: Java Edition.
- The installer isn't code-signed yet. If Windows says it protected your PC, click **More info**, then **Run anyway**.
